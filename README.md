# diaMundial

Aplicación de Android que muestra el Día Internacional que se celebra cada día del año.

## Características

- Consulta el día mundial, internacional o conmemorativo de cada fecha
- Calendario interactivo para navegar por los eventos de todo el año
- Filtrado por país y categoría (Salud, Educación, Medio Ambiente, Cultura, Ciencia y Tecnología)
- Sistema de favoritos para guardar eventos importantes
- Notificaciones diarias con hora configurable
- Compartir eventos por WhatsApp
- Crear, editar y restaurar celebraciones personalizadas
- Importar y exportar archivos JSON
- Soporte multilingüe: Español, Inglés, Francés, Chino, Japonés, Portugués y Catalán
- Tema claro, oscuro y según el sistema
- Ajuste de tamaño de fuente
- Icono adaptable al idioma seleccionado

Política de Privacidad

Última actualización: 6 de julio de 2026

Resumen breve: Día Mundial es una aplicación offline que no recopila datos personales, no contiene publicidad y no comparte información con terceros. Todos los datos se almacenan exclusivamente en tu dispositivo.

1. Datos que recopila la aplicación

Día Mundial no recopila, transmite ni almacena ningún dato personal en servidores externos. La aplicación funciona completamente sin conexión a internet.

Los siguientes datos se almacenan únicamente en tu dispositivo local:

  • Preferencias de la aplicación: tema (claro/oscuro), idioma, hora de notificación y modo de notificación.
  • Celebraciones personalizadas: días especiales que el usuario crea o modifica.
  • Favoritos: eventos marcados como favoritos por el usuario.
  • Archivo JSON importado: si el usuario importa un archivo personalizado de días mundiales.

2. Permisos que utiliza

La aplicación solicita únicamente el siguiente permiso:

  • Notificaciones (POST_NOTIFICATIONS): necesario para enviar el recordatorio diario del día mundial. Este permiso se solicita solo cuando el usuario activa las notificaciones en los ajustes.

3. Uso de datos

Los datos almacenados se utilizan exclusivamente para:

  • Mostrar la información de los días mundiales e internacionales.
  • Enviar notificaciones diarias (solo si el usuario las activa).
  • Recordar las preferencias del usuario (tema, idioma, favoritos).

4. Compartición de datos

La aplicación no comparte ningún dato con terceros. No se utilizan servicios de análisis publicitario, redes sociales ni plataformas de seguimiento.

5. Contenido compartido

El usuario puede compartir información sobre días mundiales a través de otras aplicaciones (como WhatsApp) utilizando la función de compartir del sistema operativo. Esta acción es iniciada y controlada unicamente por el usuario.

6. Servicios de terceros

La aplicación no integra ningún servicio de terceros que recopilen datos, incluyendo pero no limitado a:

  • Servicios de publicidad
  • Analíticas o estadísticas
  • Servicios de Firebase
  • Redes sociales

7. Seguridad

Al no recopilar ni transmitir datos personales, no existe riesgo de brechas de seguridad relacionadas con información del usuario. Todos los datos se mantienen en el almacenamiento local del dispositivo.

8. Privacidad de los niños

La aplicación no está dirigida específicamente a niños menores de 13 años. No recopila datos personales de ningún usuario, incluyendo niños.

9. Cambios en esta política

Si se realizan cambios en esta política de privacidad, se actualizará esta página con la fecha de revisión correspondiente.
